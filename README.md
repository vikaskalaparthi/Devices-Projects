# Devices-Projects

These projects were made during the Physics of Transistors, Microelectronics Lab, and Microfabrication and Semiconductor Processes coursework.

1. Device Simulation: Simulated PN junction diode and MOSFET devices using Synopsys Sentaurus TCAD and analyzed their electrical characteristics.

2. FinFET Fabrication: Fabricated a FinFET device and studied key semiconductor fabrication processes using SEMulator3D.
